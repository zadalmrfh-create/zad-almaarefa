زاد المعرفة — تقييم المحاضرات بعد تسجيل الحضور (12 نوفمبر 2026)

الجديد:
• تبويب جانبي جديد في لوحة الإدارة باسم «تقييمات المحاضرات».
• عند تسجيل الطالب حاضرًا من صفحة الحضور (أو تحويل الغياب إلى حاضر)، تُحفظ الحصة وإشعار تقييم خاص بالطالب معًا في عملية واحدة.
• الطالب يجد تبويب «تقييم المحاضرات» في لوحة حسابه ويرى الحصص التي حضرها.
• كل حصة لها تقييم واحد من 1–5 نجوم مع ملاحظة اختيارية حتى 500 حرف.
• الإدارة ترى متوسطات المعلمين والتقييمات، ولا يستطيع طالب قراءة تقييمات غيره أو تغيير تقييم مرسل.
• الغياب لا يرسل دعوة تقييم. لا يتم إرسال إشعارات خارج المنصة أو بريد أو واتساب.

خطوات ضرورية بعد رفع الكود على GitHub:
1- ارفع كافة ملفات ZIP إلى جذر المستودع main مع الاحتفاظ بنسخة احتياطية.
2- افتح Firebase Console > Firestore Database > Rules.
3- راجع القواعد المحدّثة في firestore.rules وانشرها من لوحة Firebase (رفع ZIP لا يغيّر صلاحيات Firestore).
4- تأكد من نجاح النشر على GitHub Pages.
5- جرّب حصة اختبار بحساب طالب حقيقي وحالة «حاضر»، ثم افتح حساب الطالب وتحقق من الإشعار والتقييم، وراجع تبويب التقييمات بالإدارة.

مهم: لو قواعد Firestore المنشورة مختلفة عن الملف المرفق، لا تستبدلها بالكامل قبل دمج قواعد lectureReviews يدويًا.
سجل تقييم المحاضرة مرتبط بمعرّف الحصة؛ لا تُحذف السجلات المالية أو التقييمات السابقة.
