ملفات تعديل جاهزة مباشرة (بدون أداة).
استبدل الملفات الموجودة في مشروعك بنفس المسارات بعد حفظ نسخة احتياطية.
تشمل بطاقة طاقم التدريس وصورة الإعلان، وتحديد محمد طلعت في الحجز والحضور، وإخفاء بلال من القوائم النشطة والمرتبات.
لا تمس قاعدة بيانات Firebase ولا تغير أو تنشئ سجلات المرتبات القديمة.
تنبيه توافق: الملفات مبنية على النسخة المتاحة محليًا من مشروعك قبل تحديثات 22 نوفمبر؛ استبدال ملفات من نسخة GitHub أحدث قد يرجع تعديلات أخرى. راجع الفروق قبل رفعها.
