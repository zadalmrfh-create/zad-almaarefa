تحديث جداول الطلاب الأسبوعية الثابتة - زاد المعرفة

هذه الحزمة تحتوي فقط على الملفات الجديدة والمعدلة بعد تحديثات المشروع السابقة، بما فيها إصلاح لوحة الإدارة والجداول. لا تفك الضغط داخل public؛ فك الضغط داخل جذر المشروع بجوار package.json مع الحفاظ على المسارات واستبدال الملفات المطابقة.
1. احتفظ بنسخة احتياطية.
2. فك الضغط داخل مجلد المشروع الرئيسي.
3. شغّل npm run release:check باستخدام Node.js 24 لديك.
4. ارفع التعديلات إلى GitHub وانشر public الناتج بالطريقة المعتادة.

الاستخدام: لوحة الإدارة > جداول الطلاب > اختر الطالب > عنوان الحصة والمادة > موعد أسبوعي ثابت > اختر أيام الأسبوع والساعة بنظام 24 ساعة > تاريخ البداية (اليوم افتراضيًا) > تاريخ نهاية اختياري > احفظ الموعد الثابت. مثال: السبت والأربعاء 9 مساءً = اختر اليومين و21:00. إذا اختلفت ساعة يوم عن آخر، سجل موعدًا مستقلًا لكل ساعة.

تظهر المواعيد في جدول الطالب للأسبوع الحالي والقادم، وصفحة الحصة وتحديد الحصة القادمة. تعرض قائمة المحاضرات المواعيد الأسبوعية من أمس حتى 14 يومًا قادمة عند تحميل الصفحة، ولا يتم إنشاء وثيقة جديدة لكل تكرار. إذا تركت النهاية فارغة يستمر الموعد. زر تعديل يغير قاعدة التكرار بالكامل، وزر إيقاف التكرار يخفي المواعيد المحسوبة من الجدول. لتحديد آخر يوم يظهر فيه الموعد استخدم تاريخ النهاية. الحصص القديمة لمرة واحدة تبقى كما هي ويمكن اختيار نوع موعد لمرة واحدة عند الحاجة. لا يتغير سجل الحضور الرسمي أو المدفوعات، ولا تُنشأ سجلات حضور تلقائيًا. المواعيد المحسوبة ليست سجلًا تاريخيًا ثابتًا مستقلًا عن قاعدة التكرار.

البيانات تستخدم مجموعة studentSchedules/{studentUid}/lessons الحالية، وتضيف recurrence وweekdays وendDate إلى سجل الموعد. لا تحتاج الحزمة إلى قواعد Firestore جديدة إذا كانت قواعد studentSchedules الخاصة السابقة منشورة بالفعل. الطالب يستطيع قراءة جدوله الخاص فقط وفق القواعد الحالية، والإدارة وحدها تستطيع تعديله. لا تتضمن الحزمة بيانات الطلاب أو أرقام هواتفهم ولا تُدخل أي مواعيد فعلية تلقائيًا.

التحقق: نجحت 95 حالة اختبار، وفحص 161 ملف JavaScript و34 سكربت مضمّنًا و138 مرجعًا، وبناء والتحقق من 300 ملف. استخدم الفحص المحلي Node.js 22.16.0؛ المشروع يستهدف Node.js 24. تم اختبار نموذج الإدارة الحقيقي مع بديل Firestore وهمي في Chromium بعرض 375 بكسل (إنشاء وتعديل وإيقاف الموعد وتسجيل حصة لمرة واحدة). لم يُختبر الحفظ على Firebase الحية أو النشر على موقعك. جرّب موعدًا في حساب اختبار بعد النشر.
