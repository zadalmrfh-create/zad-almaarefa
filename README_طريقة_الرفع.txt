تحديث زاد المعرفة: طاقم التدريس + صورة الخلفية الأصلية.

1- فك الضغط، وانسخ الملفات والمجلدات الستة إلى جذر مستودع GitHub الجديد بنفس المسارات (لا تنسخ ملف TXT).
2- استبدل الملفات المطابقة فقط.
3- ارفع التعديلات بـ GitHub Desktop: Commit ثم Push.
4- اعمل Ctrl+F5 على الموقع.

التعديل: إخفاء بلال من طاقم التدريس حتى إن كانت البطاقة موجودة في Firebase، إضافة محمد طلعت بإعلانه كاملًا دون تكرار، والعودة لخلفية المكتبة القديمة بدل الكحلي السادة في الرئيسية.

مهم: هذا تعديل للواجهة فقط من ملف step6 الذي أرسلته، ولا يحذف حساب بلال من Firebase ولا يغيّر المرتبات والحضور والحجز أو قواعد Firestore.
