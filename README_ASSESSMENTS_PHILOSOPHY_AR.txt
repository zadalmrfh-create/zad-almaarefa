تحديث مكتبة زاد المعرفة — إضافة قسم التقييمات
=========================================
القسم الجديد: المكتبة ← التقييمات ← الفلسفة والمنطق.
الملفات الستة تخص الصف الأول الثانوي العام، الفصل الدراسي الثاني، الأسابيع 1–6.
تشمل التقييمات الأسبوعية والأداء الصفي والواجب المنزلي، مع 3 نماذج للأسبوع الثالث.
المحتوى كما ورد في الملفات المرفوعة دون تعديل.
لا توجد إعادة لزر الثانوية العامة أو البكالوريا في اختيار المرحلة.
يمكن تصفح أسماء التقييمات دون دفع؛ زر «فتح / تحميل التقييم» يمر بصفحة book-access.html وفحص اشتراك المكتبتين.
