# تفعيل حماية ملفات متجر زاد المعرفة — مطلوب قبل البيع

## ما الذي تغيّر؟

1. اختفت أزرار المعاينة المجانية للملفات ودروس الكورسات.
2. صفحة المتجر تقرأ بيانات العرض الآمنة من `storePublicProducts`، ولا تقرأ مستندات المنتجات الخاصة `storeProducts`.
3. `catalog-data.js` لا يحتوي على روابط الكتب أو ملفات MEGA أو Google Drive أو مسارات Storage.
4. تحميل PDF يعتمد فقط على صلاحية الطالب في `storeEntitlements/{uid}_{productId}`. يصدر الأدمن هذه الصلاحية بعد اعتماد التحويل وتخزين ملف آمن. للشراء يجب أن تكون `deliveryReady = true`.
5. أي ملف لم يُرفع إلى المسار المحمي `storeProtected/{productId}/...` يظل **غير جاهز للبيع**؛ يراه الطالب في الكتالوج لكنه لا يستطيع إضافته للسلة.

## تنبيه حاسم

هذه الملفات وحدها **لا تمنع** الدخول إلى روابط PDF التي سبق نشرها علنًا على GitHub Pages أو Drive أو MEGA. الروابط العامة لا تستطيع قواعد Firebase إغلاقها. يجب حذف النسخ القديمة من المستودع المنشور وإلغاء مشاركة الروابط العامة، وإلا سيظل الملف قابلًا للوصول خارج المتجر حتى لو اختفى زر المعاينة.

## خطوات التفعيل بالترتيب

1. احتفظ بنسخة احتياطية من مشروعك وقواعد Firebase.
2. في **Firestore Database → Rules** استبدل القواعد بالنص الكامل الموجود في جذر المشروع `firestore.rules` بعد مراجعته، ثم انشره.
3. في **Firebase Storage → Rules** أضف محتوى `store/storage-store-snippet.rules` **داخل** قواعد Storage الحالية، ولا تحذف قواعد الأكاديمية الأخرى. تحقق أن أية قاعدة عامة أخرى لا تسمح بقراءة ملفات `storeProtected/**` بلا صلاحية.
4. اعتمد نسخة **النشر الآمنة** من المشروع. لن تحتوي النسخة على ملفات `/sections/**/*.pdf` القديمة. في مستودع GitHub احذف الملفات القديمة المتتبعة من Git ثم Commit ثم Push — نسخ ZIP الجديد فوق الملفات القديمة وحدها لا يحذفها. أزل كذلك أي نسخ عامة أخرى، وتحقق من الروابط القديمة مباشرة في نافذة خفية. لا ترفع النسخ الخاصة إلى GitHub.
5. المنتجات تظل ظاهرة بالأسماء والأسعار. من صفحة **إدارة المتجر → المنتجات → تعديل منتج** ارفع ملف PDF المرخّص إلى Firebase Storage وأكمل الحفظ. لا يوجد زر إضافة منتج.
6. اختياريًا للملفات المحلية التي تملك حق توزيعها، استخدم `store/tools/migrate_local_pdfs.py` من جهازك لتجهيز 29 ملف PDF محليًا دفعة واحدة. ستحتاج Python وحزمة `firebase-admin` وحساب خدمة Firebase محفوظًا خارج المشروع. لا ترفع ملف حساب الخدمة ولا كلمة سرّه إلى GitHub.
7. للروابط القديمة على MEGA أو Drive: احصل على نسخة أصلية مرخصة، وارفعها بشكل محمي. احذف أو ألغِ مشاركة الرابط العام عند المصدر. لن يقوم النظام بتنزيل الملفات أو إعادة نشرها تلقائيًا.
8. اختبر **حساب طالب غير مسجل**، ثم **طالب مسجل لم يدفع**، ثم **طالب أرسل تحويلًا قيد المراجعة**: يجب رفض فتح الملف في الحالات الثلاث. بعد اعتماد الإدارة والتحقق من مبلغ التحويل جرب حساب الطالب الذي تم الشراء باسمه فقط. جرب حساب طالب آخر للتأكد من رفض الوصول.

## ملاحظات تشغيل

- بطاقة المنتج التي لم تُحمّل لها نسخة محمية تعرض «المحتوى تحت التجهيز والحماية»، بدل زر الإضافة للسلة. ده مقصود لحمايته ومنع قبول مبالغ مقابل ملف غير جاهز.
- الملفات التي سبق إصدار رابط تنزيل علني لها من Firebase Storage باستخدام download token لا تصبح محمية تلقائيًا بقواعد Storage؛ يجب إبطال التوكنات والروابط العامة القديمة.
- حماية ملف PDF من فتحه دون دفع **لا تمنع مشتريًا مصرحًا له من مشاركته بعد تنزيله**. هذا يحتاج سياسات وعلامة مائية/عرضًا مقيدًا إضافيًا؛ ولا توجد حماية مطلقة ضد نسخ المحتوى.
- إن كانت روابط لمواقع خارجية أو محتوى محفوظ لدى جهة أخرى، لا يمكن للمتجر سحب أو إلغاء تلك الروابط بنفسه.
- الملفات والحصص والكورسات المضافة بالفعل تظل محفوظة؛ التطبيق يوقف الوصول غير المصرح حتى ينتهي تفعيل قواعد Firestore وStorage وتأمين مخازن المحتوى.
