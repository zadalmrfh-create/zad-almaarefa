لوحة زاد المعرفة - تبديل اللوحات للأدمن

من لوحة الإدارة اضغط «تبديل اللوحة» واختر المعلم أو الطالب المراد معاينة حسابه.
تفتح اللوحة المطلوبة باستخدام جلسة الأدمن الحالية دون تغيير role أو تسجيل خروج.
المعاينة قراءة فقط: يمنع إرسال النماذج وتعديل/حذف البيانات وإجراء عمليات مالية أو دخول المحاضرات من واجهة المعاينة.
العودة إلى لوحة الأدمن من الشريط الأصفر.
بعض البيانات الخاصة بتسجيل الطالب (مثل المكتبة الشخصية) قد لا تظهر إذا كانت قواعد Firestore تسمح بقراءتها لصاحب الحساب فقط.
القواعد الحالية لم تُوسَّع لمنح صلاحيات إضافية؛ استخدم حسابات تجريبية عند اختبار الكتابة.
