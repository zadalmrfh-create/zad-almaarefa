زاد المعرفة — إصلاح permission-denied عند فتح امتحانات الوحدة الأولى

السبب المحتمل المؤكد في كود النسخة السابقة:
- صفحة sections/tests/unit-one-exam.js تعمل getDoc لمحاولة الطالب قبل بدء امتحان الوحدة الأولى.
- Firestore rules في النسخة القديمة تحاول مقارنة resource.data.studentUid بUID الطالب حتى عندما تكون الوثيقة غير موجودة (أول محاولة)، لذلك يمكن أن ينتهي الطلب برفض القراءة.

الإصلاح:
- السماح بعملية get لمعرف محاولة الطالب فقط وهو request.auth.uid + "_" + examId في قائمة الامتحانات المحددة، سواء وُجدت الوثيقة أم لا.
- استمرار منع list من غير الأدمن، مع إبقاء create/update/delete منضبطة دون تغيير.
- إظهار رسالة إرشادية إذا كانت القواعد لم تُنشر بعد.

التشغيل (خطوتان مطلوبتان):
1) انشر المشروع المحدث على GitHub Pages.
2) انشر firestore.rules الموجود في الجذر من Firebase Console > Firestore Database > Rules، بعد أخذ نسخة من القواعد الحالية.
   في حال كانت القواعد المنشورة مختلفة عن قواعد المشروع، ادمج تعديل unitOneExamAttempts فقط بدل استبدال قواعد الإنتاج كلها.

الاختبارات: افتح الامتحان بحساب طالب جديد (get لوثيقة غير موجودة)، وبعد التسليم افتحه مجددًا للتأكد من منع الإعادة؛ جرّب محاولة طالب آخر للتأكد من رفض الاطلاع؛ اختبر عرض نتائج الكل بحساب الأدمن.

ملاحظة: إعداد Firebase الحقيقي لم يُختبَر في هذه البيئة.
