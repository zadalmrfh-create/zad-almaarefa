# تحسين ظهور الروابط المهمة في زاد المعرفة

- يظهر «⭐ آراء الطلاب» و«💳 سياسة المدفوعات» مباشرة في الشريط العلوي على الكمبيوتر.
- على الشاشات المتوسطة والهواتف، يظهر شريط ثابت للرابطين أسفل شريط التنقل دون الحاجة لفتح «المزيد».
- داخل قائمة الهاتف يظهر الرابطان أيضًا في الأعلى بصورة مميزة.
- أزيل الرابطان من قائمة «المزيد» لتجنب التكرار.
- أضيف رابط آراء الطلاب إلى الفوتر، وسياسة المدفوعات إلى البحث.
- لم تتغير ملفات Firebase أو بيانات الطلاب أو المدفوعات أو صلاحيات الإدارة.
