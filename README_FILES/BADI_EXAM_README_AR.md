# امتحان علم البديع — الصف الثاني البكالوريا

- الامتحان في المكتبة → الامتحانات الإلكترونية المجانية → البكالوريا → الصف الثاني البكالوريا → البلاغة — علم البديع.
- رابط مباشر: `sections/tests/unit-one-exam.html?id=badi-2bac-2026`.
- بنك الأسئلة: `exams/unit1/bank.json`، يتضمن 30 سؤالًا (26 موضوعيًا + 4 مقالي).
- كل الأسئلة تدريبية أصلية على الموضوعات التي ظهرت في ملف «أسئلة عامة على علم البديع» ص 79–84، وليست نسخًا حرفيًا.
- يجب أن يسجل الطالب الدخول بحساب Firebase Auth، وأن يكتب اسمًا لا يقل عن 3 أحرف.
- توجد محاولة واحدة لكل طالب لكل امتحان، تُحفظ في `unitOneExamAttempts/<uid>_badi-2bac-2026`.
- تظهر المحاولة فور حفظها للأدمن في لوحة الإدارة → نتائج الامتحانات / تصحيح المقالي.
- التصحيح الموضوعي تلقائي مبدئي (26 نقطة)، والمقالي يصححه الأدمن يدويًا (4 نقاط)، والدرجة النهائية بعد اعتماده.
- يمكن للطالب بعد تسليم المحاولة طباعة النتيجة (الأولية أو النهائية المعتمدة) وتقرير إجاباته.

## ضروري قبل الاختبار

1. ارفع ملفات التحديث مع الحفاظ على المجلدات.
2. ادمج التعديل الموجود في `firestore.rules` مع قواعد Firebase الحيّة وانشره. لا تستبدل قواعد أحدث دون مقارنة.
3. جرّب بحساب طالب: الدخول مطلوب، الاسم مطلوب، التسليم، ثم جرب حساب الأدمن لمراجعة المقالي.
4. لا تعلن تفعيل الامتحان حتى تتأكد من اختبار Firestore الحيّ. لم يتم تشغيل هذا الاختبار هنا.

الامتحان مجاني ومستقل عن مدفوعات المتجر.
