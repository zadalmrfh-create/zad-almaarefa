# تحديث فصل الامتحانات الإلكترونية المجانية

- افتح `sections/library.html`: الامتحانات الإلكترونية موجودة ومجانية من غير أي دفع.
- `sections/tests/code-exams.html`: امتحانات Firebase المنشورة وامتحانات الوحدة الأولى.
- `sections/tests/index.html`: اختبارات المواد حسب المرحلة والصف، ومنها النحو والبلاغة والتوحيد.
- تتطلب الامتحانات الموجودة تسجيل الدخول بحساب الأكاديمية وفق النظام القديم؛ لا تشترط شراء ولا اعتماد دفع.
- تم إخراج المنتجات `lib-101` و`lib-102` (اختبار النحو واختبار التوحيد التفاعليان) من بيانات المتجر، مع منع ظهورهما حتى لو كانت لهما مستندات قديمة في Firestore.
- **امتحانات PDF الورقية ما زالت منتجات مدفوعة داخل المتجر**، حسب نظام الأسعار الحالي.
- تم تعديل `firestore.rules` لمنع إنشاء طلبات شراء جديدة لهذين الاختبارين التفاعليين. ادمج هذا الشرط في القواعد المنشورة إذا كانت أحدث من الملف المرفق، ولا تستبدل قواعد حية أحدث دون مراجعة.
- لم تُحذف أي طلبات قديمة أو سجلات درجات أو سجلات دفع من Firebase.
- لا تحتاج لرفع ملفات PDF أو الروابط الخارجية لتشغيل الامتحانات الإلكترونية القديمة.
- جرّب دخول حساب طالب إلى المكتبة ثم اختبار مجاني وتأكد من حفظ النتيجة. الاختبار المباشر على Firebase لا يمكن تنفيذه هنا.
