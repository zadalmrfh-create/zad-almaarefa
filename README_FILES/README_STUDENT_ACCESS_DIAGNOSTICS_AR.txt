تشخيص عدم ظهور سجلات الطالب عند الدخول الحقيقي — أكاديمية زاد المعرفة

سبب مهم: المعاينة الإدارية تقرأ بصلاحيات الأدمن؛ ليست بديلاً عن اختبار حساب الطالب.

1) في المعاينة الإدارية افتح حضوري، واضغط «فحص ربط حسابي بالسجلات» وسجّل UID الطالب المستهدف وعدد الحصص.
2) سجّل الخروج وادخل بحساب الطالب الحقيقي. افتح «حضوري» واضغط الزر نفسه.
3) إذا اختلف UID الحساب الحقيقي عن UID المعاينة: تم اختيار حساب مستخدم آخر عند تسجيل الحصص. صحّح ربط السجلات من لوحة الإدارة بعد التأكد من البريد ومعرّف الحساب. لا تربط السجلات بالاسم وحده.
4) إذا UID متطابق ويظهر permission-denied: افتح Firebase Console > Firestore Database > Rules وانشر القواعد المتوافقة مع مشروعك. رفع ملف firestore.rules على GitHub لا ينشر القواعد. قواعد المشروع المرفقة في النسخة السابقة تسمح لصاحب studentUid بالقراءة.
5) إذا UID متطابق ولا توجد أخطاء ولكن عدد السجلات صفر: تأكد أن النسخة التي تراجعها والمنصة تستخدمان نفس Firebase projectId وأن سجلات الحضور والمدفوعات محفوظة تحت studentUid ذاته.

التعديل يضيف تقرير تشخيص واضح فقط، ولا يغير قاعدة البيانات ولا يكشف سجلات طلاب آخرين.
