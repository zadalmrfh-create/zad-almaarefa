# متابعة تقرير إجابات نحو — Jana M’Sophy

## المشكلة
كان تقرير الطالب القديم يحفظ أرقام خانات الاختبار وإجاباتها فقط، ولا يحفظ نص السؤال أو الإجابة الصحيحة لكل خانة. درجة 10 / 11 مسجلة من كود الامتحان، وليست توثيقًا بأن كل خانة في التقرير صُححت حسب مفتاح معتمد.

## معرّف الامتحان
`Q72eQHwXHxeFdVjBfp0m`

## استيراد نص السؤال
1. افتح لوحة الأدمن ← نتائج الامتحانات الإلكترونية.
2. افتح نتيجة الطالبة واضغط «📝 الإجابات النموذجية».
3. اضغط «📥 استيراد نصوص الأسئلة»: يقرأ الزر كود الامتحان الأصلي من Firebase ويحاول وضع نص السؤال أمام الخانة المقابلة.
4. **راجع كل مطابقة بنفسك**؛ ترقيم الخانات في بعض النتائج القديمة لا يساوي ترقيم أسئلة الامتحان. لا تحفظ مفتاحًا غير مؤكد.
5. اكتب الإجابات الصحيحة بعد مراجعة ورقة الامتحان، ثم اضغط «حفظ مفتاح الإجابات».
6. اطبع تقرير الإجابات مجددًا.

## لو نص السؤال لم يُستورد
اضغط «📄 تنزيل HTML الامتحان» من نفس النافذة، ثم افتحه لعرض كوده أو ارفعه للمراجعة. الامتحانات التي تولّد أسئلتها بواسطة JavaScript قد لا تسمح باستخراج نصوص الأسئلة من كود HTML الثابت وحده.

## سلامة البيانات
لا يتم تعديل أو حذف سجلات إجابات قديمة ولا تغيير درجتها آليًا. يتم التقاط إجابات المحاولات الجديدة عند التسليم قبل أن يعيد الامتحان رسم الصفحة. هذا التعديل لا ينشر قواعد Firebase ولا يغني عن اختبار صلاحيات الأدمن وحفظ المفتاح في المشروع الفعلي.
