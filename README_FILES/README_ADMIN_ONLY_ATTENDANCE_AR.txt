تعديلات منصة زاد المعرفة — الحضور والغياب (للإدارة فقط) + اللغة العربية (عام)

التعديلات:
1- لوحة المعلم: تم إلغاء نموذج تسجيل الحضور والغياب وإلغاء زر حذف سجلات الحضور. يستطيع المعلم الاطلاع على سجلات طلابه والتقارير فقط.
2- لوحة الإدارة: تظل إضافة الحضور وتعديله وحذفه متاحة كما كانت.
3- تمت إضافة «اللغة العربية (عام)» إلى قائمة المواد في تسجيل الحضور بلوحة الإدارة، وعند اختيارها يظهر المعلم أ/ ضياء الدين نبيل تلقائيًا، مثل باقي مواد اللغة العربية.
4- تم تحديث firestore.rules لمنع أي حساب معلم من إنشاء أو تعديل أو حذف المستندات في lessonAttendance حتى لو حاول تنفيذ الطلب خارج الواجهة.

خطوات التطبيق:
أ) انشر ملفات الموقع المعدلة على نفس استضافتك، وخاصة dashboard/teacher/index.html وdashboard/teacher/teacher-enhancements.js وdashboard/attendance-subjects.js.
ب) مهم جدًا: افتح Firebase Console > Firestore Database > Rules، واستبدل القواعد الحالية بمحتوى ملف firestore.rules ثم اضغط Publish. رفع ملف القواعد على استضافة الموقع وحده لا يطبق صلاحيات Firebase.
ج) حدّث الصفحة تحديثًا إجباريًا Ctrl+F5.

تنبيه: هذه النسخة لا تغير أي سجلات حضور أو مدفوعات موجودة مسبقًا في Firestore.
