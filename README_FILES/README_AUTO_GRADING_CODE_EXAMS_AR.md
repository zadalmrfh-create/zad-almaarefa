# التصحيح التلقائي لامتحانات HTML — زاد المعرفة

## طريقة العمل

- عند ضغط الطالب **تسليم**، يلتقط نظام الربط إجابات الطالب **قبل تغيير الصفحة**.
- إذا كان كود الامتحان يعرض نتيجة صحيحة مُحتسبة بالفعل، تُحفظ الدرجة التي أخرجها الامتحان تلقائيًا.
- إذا لم يكن الامتحان يعرض درجة، لكن كل الأسئلة الموضوعية لها مفتاح إجابات واضح في الكود، تقارن المنصة الإجابات تلقائيًا وتحسب درجة **الأسئلة الموضوعية فقط**.
- يُحفظ مع الإجابات نص السؤال والمفتاح الصحيح وحالة المطابقة عندما يمكن اكتشافها، وتظهر في تقرير الطالب والأدمن.
- يبحث النظام عن `correctAnswers` و`answerKey` و`modelAnswers` وغيرها، أو وسوم HTML مثل `data-correct-answer` و`data-correct="true"`، وكذلك المفاتيح التي كُتبت داخل دالة في صورة كائن JavaScript ثابت.
- عند طباعة تقرير نتيجة قديمة، تحاول لوحة الأدمن قراءة مصدر الامتحان المحفوظ في Firebase واستخراج الإجابات النموذجية تلقائيًا؛ دون تغيير الدرجة المحفوظة.

## لتعمل المقارنة الآلية الموثوقة في امتحان جديد

يفضّل تضمين مفتاح واضح في كود الامتحان على صورة:

```html
<script>
const correctAnswers = { q1: 'b', q2: false, q3: 'الإعراب' };
</script>
```

بحيث تتطابق أسماء الأسئلة `q1` و`q2` و`q3` مع خاصية `name` لعناصر الإجابة في HTML، أو وضع `data-correct-answer="..."` على حاوية السؤال، أو `data-correct="true"` على خيار واحد صحيح. **هذه مجرد أمثلة؛ لا تلزم إدخالها إن كان الكود الحالي يحتوي بالفعل على مفتاح واضح يمكن اكتشافه.**

## حالات لا يمكن الجزم بصحتها آليًا

- الإجابات المقالية الحرة: تحتاج مراجعة المعلم أو الأدمن، حتى لو كان هناك نموذج استرشادي.
- مفاتيح التصحيح المحسوبة وقت التشغيل أو المخفية داخل شيفرة معقدة: لا يستطيع الفاحص دائمًا إعادة بنائها من HTML. يعرض التقرير الدرجة التي حسبها الامتحان إن توفرت، ولا يخترع إجابات نموذجية.
- النتائج القديمة قد تكون حُفظت بأرقام خانات، لا أرقام الأسئلة. تظهر أي مقارنة مستخرجة من الكود بحالة «مبدئية» وتحتاج التحقق من الترتيب.
- الدرجة القادمة من كود HTML على متصفح الطالب ليست تصحيحًا معتمدًا من خادم محمي. اعتماد النتائج النهائية والشهادات الرسمية مسؤولية الإدارة.

## اختبار Firebase الحقيقي

هذا التعديل لا يضيف حقولًا جديدة إلى وثيقة `codeExamResults`؛ الإجابات محفوظة في الحقل النصي `answers` الموجود بالفعل، وبالتالي لا يلزم تعديل Firestore Rules لهذه الميزة وحدها إن كانت القواعد السابقة منشورة. يحتاج الأمر تجربة على حساب طالب حقيقي وحساب أدمن قبل النشر النهائي.
