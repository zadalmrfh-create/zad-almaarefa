# تعديل طاقم التدريس

- أُخفيت المعلمة فاطمة أشرف من صفحة طاقم التدريس في كل حالات التحميل، بما في ذلك سجلات Firebase القديمة.
- لاستكمال حذف سجلها من قاعدة Firebase الحية، افتح `dashboard/admin/remove-teacher-record.html` بحساب أدمن واضغط «حذف سجل فاطمة أشرف من Firebase». لا يمكن تنفيذ هذا الحذف من ملف ZIP وحده.
- لا يحذف هذا الإجراء حساب Firebase Authentication ولا سجلات الحضور والمرتب التاريخية حتى لا تتلف القيود المالية.
- استُعيدت صور الإعلان الأصلية لفاطمة ضياء ومحمد خالد محمود بعد تغطية عرض «أول حصة مجانية» بعبارة «احجز حصتك الآن» مع الحفاظ على معظم التصميم الأصلي.
- إذا خزّن المتصفح الصور القديمة، اضغط Ctrl+F5 بعد النشر.
