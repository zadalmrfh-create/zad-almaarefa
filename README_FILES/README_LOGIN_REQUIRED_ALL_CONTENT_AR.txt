زاد المعرفة — تعديل حماية المكتبة وكل المحتوى التعليمي (29-10-2026)
=========================================================

تم تعديل 20 صفحة تعليمية، منها:
- المكتبة التعليمية، وصفحة تفاصيل الكتاب.
- صفحات المواد والمحتوى الدراسي: التعليم الأزهري، اللغة العربية والدروس، القرآن وفروعه، الشريعة، التزكية.
- جميع صفحات الاختبارات الحالية، بما فيها امتحانات الوحدة الأولى والامتحانات الإلكترونية.

السلوك الجديد:
1. الزائر غير المسجل لا تظهر له محتويات هذه الصفحات، وإنما شاشة «تسجيل الدخول مطلوب» وبها رابط لتسجيل الدخول أو إنشاء حساب.
2. مستخدم Firebase Authentication المسجل يمكنه فتحها بصورة طبيعية.
3. إذا سجّل الطالب الدخول أو أنشأ حسابًا بعد فتح صفحة محمية، يعود إلى نفس الصفحة مع الاحتفاظ بمعلمات الرابط.
4. عند تعذر اتصال Firebase، تظهر رسالة واضحة بدل استمرار «جارٍ التحقق» بلا نهاية.
5. أصبح مساعد الصفحة الرئيسية يعرض عناوين الكتب ورابط المكتبة بدل إعطاء روابط ملفات الكتب الخارجية مباشرة.

الملفات المهمة:
- assets/content-auth-guard.js و assets/content-auth-guard.css
- assets/content-auth-fallback.js
- login/login.js و login/register.js
- sections/tests/exam-auth-gate.js
- firestore.rules

طريقة النشر:
1. ارفع محتويات ZIP للمستودع نفسه في GitHub مع الحفاظ على مسارات المجلدات، ثم انتظر نشر GitHub Pages.
2. افتح الموقع، وجرّب في نافذة تصفح خفي رابط sections/library.html؛ يجب أن تظهر شاشة «تسجيل الدخول مطلوب».
3. اضغط تسجيل الدخول، وسجل بحساب مستخدم حقيقي؛ يجب أن تُفتح المكتبة بعد الدخول.
4. جرّب روابط sections/book.html و sections/tests/index.html و sections/tests/code-exams.html و sections/Arabic/lesson.html.
5. لبدء تطبيق قواعد قاعدة البيانات المحدّثة، افتح Firebase Console > Firestore Database > Rules، وانسخ محتويات firestore.rules كاملة وانشرها (Publish). رفع الملف إلى GitHub وحده لا ينشر القواعد على Firebase.
6. بعد التعديل امسح كاش المتصفح بـ Ctrl+Shift+R.

ملاحظة حماية مهمة للغاية:
هذا المشروع موقع ثابت منشور عبر GitHub Pages. حماية واجهة HTML باستخدام Firebase Auth لا تمنع
أحدًا يعرف رابط ملف PDF المباشر من فتحه أو تنزيله خارج الموقع، سواء الملف موجودًا ضمن المستودع
(مثل sections/summaries/*.pdf) أو على Google Drive أو مصدر خارجي. كما أن محتوى HTML الثابت
يمكن رؤيته من مصدر الصفحة. الحماية الحقيقية على مستوى الملفات تتطلب نقل المحتوى إلى تخزين خاص
مثل Firebase Storage بقواعد تمنع القراءة من غير المسجلين، أو تقديمه من خادم يتحقق من الهوية.
لم ننقل ملفات أو نغيّر روابطها هنا حتى لا تنقطع الكتب والملخصات الحالية؛ وهذا التعديل يقيّد
الوصول من واجهة الموقع ويقيّد قراءات Firestore للمجموعتين libraryBooks و azharBooks عند نشر القواعد.
