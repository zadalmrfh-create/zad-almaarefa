# إلغاء صلاحية المعلم وتحويله إلى طالب — زاد المعرفة

## طريقة الاستخدام
1. افتح لوحة الأدمن > المستخدمون.
2. ابحث عن الحساب المسجل كمعلم.
3. اضغط «🎓 إلغاء صلاحية المعلم» ثم أكد التحويل.
4. تُحدّث وثيقة `users/{uid}` إلى `role: student` و`status: active`، ويبقى الحساب نفسه موجودًا في Firebase Authentication.
5. يستطيع صاحب الحساب الدخول للوحة الطالب بنفس البريد وكلمة المرور.
6. لا يمكنه الوصول إلى لوحة المعلم أو بيانات المعلمين، لأن دالة `isTeacher()` في `firestore.rules` تتحقق من الدور والحالة من قاعدة البيانات.

## الحفاظ على التاريخ
لا تُحذف الحصص أو الحجوزات أو المرتبات أو سجلات الطلاب السابقة. وتبقى البيانات المالية السابقة محفوظة حتى لو خرج المعلم من قائمة المعلمين النشطين.

## متطلبات الأمان
- يجب أن تكون قواعد Firestore في المشروع مطابقة لقواعد الملف `firestore.rules` المرفق ومفعلة فعليًا. لا يكفي إخفاء الواجهة.
- ينبغي تجربة التحويل بحساب معلم تجريبي، مع فتح لوحة المعلم في تبويب ثانٍ للتأكد من تحويله تلقائيًا إلى لوحة الطالب.
- لا يغيّر الإجراء محتويات أي مجموعة `admins`؛ لا يظهر الزر أمام حسابات الأدمن.
- لا يُعطّل الحساب ولا يحذفه؛ إذا أردت منع تسجيل الدخول كله فاستخدم الحظر منفصلًا.
