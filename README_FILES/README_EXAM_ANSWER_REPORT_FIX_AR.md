# تحديث تقارير إجابات الطلاب — زاد المعرفة

## ما الذي تغير؟
- تقرير الإجابات يعرض الأسئلة (إن كانت محفوظة) مع إجابة الطالب والإجابة الصحيحة في مساحتين منفصلتين.
- يتم تمييز المطابق للمفتاح الإداري باللون الأخضر والمختلف بالأحمر. الأسئلة المقالية تحتاج مراجعة بشرية.
- قيم true و false تظهر بالعربية «صح» و«خطأ».
- نتائج امتحانات الكود القديمة تُقرأ مع الحفاظ على الإجابات المقالية متعددة الأسطر وعدم تقسيمها إلى أسئلة وهمية.
- امتحانات الكود الجديدة تحفظ بيانات السؤال/نوعه/الإجابة بصورة منظمة داخل حقل answers الحالي، دون تغيير سجلات المدفوعات أو الحضور.

## خطوة ضرورية للأدمن في امتحانات الكود (HTML)
تقرير الإجابات القديم كان يحفظ إجابات الطالب فقط، ولا يحفظ إجابة صحيحة موثوقة أو نص السؤال.

1. ادخل لوحة الأدمن ← نتائج الامتحانات الإلكترونية.
2. بجانب نتيجة امتحان الكود اضغط «📝 الإجابات النموذجية».
3. اكتب نص السؤال والإجابة الصحيحة في كل خانة. للأجوبة المقبولة المتعددة استعمل || بين البدائل.
4. في السؤال المقالي اختر «مقالي (تصحيح بشري)» ولا تعتمد على مقارنة النص كحكم نهائي.
5. اضغط «حفظ مفتاح الإجابات».
6. اضغط «طباعة تقرير الإجابات»؛ سيظهر التقرير والمقارنة لجميع نتائج هذا الامتحان بحسب الخانات الموجودة في كل سجل.

**تنبيه مهم:** بعض السجلات القديمة ترتّب خانات الإدخال بدل أرقام الأسئلة الحقيقية وقد تشمل بيانات اسم الطالب والصف. راجع ربط كل خانة بالسؤال قبل اعتماد أي مقارنة. لن تستعيد المنصة نصوص الأسئلة الصحيحة من سجل قديم لم تكن محفوظة فيه أصلًا.

## قواعد حماية مفتاح التصحيح
أضيفت مجموعة Firestore جديدة: `codeExamAnswerKeys/{examId}`، بصلاحيات قراءة وكتابة للأدمن فقط.
يجب **دمج ونشر** تعديلات `firestore.rules` ضمن قواعد مشروع Firebase الحالية قبل استخدام حفظ المفتاح، وليس استبدال قواعد حيّة مختلفة دون مراجعة.
الطلاب لا يقرؤون المفتاح الإداري من قاعدة البيانات.

## مهم قبل النشر
- رفع ملفات HTML/JS/CSS على الاستضافة لا ينشر قواعد Firestore تلقائيًا.
- اختبر بحساب أدمن مخوّل فتح مفتاح الإجابات وحفظه ثم طباعة تقرير من نتائج الكود.
- اختبر بحساب طالب تسليم امتحان جديد لتتأكد من حفظ الإجابات المنظمة.
- هذه نسخة تعديل للكود، ولم يُجرَ اختبار فعلي على قاعدة بيانات Firebase الحية.
