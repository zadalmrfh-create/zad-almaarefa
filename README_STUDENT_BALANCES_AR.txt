زاد المعرفة — كشوف حسابات مستقلة لكل طالب (تعديل نوفمبر 2026)

1- لوحة الإدارة / المدفوعات: تمت إزالة تجميع الأرصدة المالية للطلاب في خانات عامة، وأضيف كشف حساب مستقل لكل طالب مع البحث والتصفية.
2- يوضح كل حساب: إجمالي تحويلاته المعتمدة بالسجل الجديد؛ قيمة حصصه؛ المدفوع المسجل للحصص؛ إجمالي المقدم؛ ما استُهلك من المقدم؛ الباقي له؛ وما عليه من مستحقات.
3- مثال: طالب دفع 225 جنيه مقدمًا، أخذ حصة بـ75 جنيه -> المتاح له 150 جنيه، وليس 0، وعليه 0.
4- في ملخص حضور الإدارة يظهر «له رصيد» أو «عليه مستحقات» (على مستوى كل المواد)، حتى لو دفع الطالب مقدمًا ولم يحضر بعد.
5- لوحة الطالب والتقرير الشامل يميزان بين المبالغ التي للطالب والمستحقات التي عليه.
6- احتساب الرصيد يتم برقم حساب الطالب studentUid، بلا خلط مع طلاب آخرين، وبالقرش لتجنب التقريب.
7- تم الحفاظ على حظر تسجيل الحضور والغياب للمعلمين وتعيين أ/ ضياء الدين نبيل لمادة اللغة العربية (عام).
8- السجل القديم للتحويلات يظل أرشيفًا للمراجعة فقط حسب إعدادات المنصة السابقة؛ لا نحذف بيانات أو نغير قواعد Firestore ولا نعتمد أي دفع تلقائيًا.
9- أي تحويل مرتبط بحصة ملغاة يظهر كتحذير تسوية يدوية ولا يُعاد كرصد تلقائي.
10- التعديل حسابات وعرض فقط؛ لا يغير بيانات Firebase الموجودة. ارفع ملفات المشروع كاملة أو الملفات المعدلة بنفس المسارات.
