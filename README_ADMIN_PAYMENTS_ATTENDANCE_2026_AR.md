# تطوير لوحة الأدمن — المدفوعات والحضور والغياب

## المدفوعات
* عند فتح «المدفوعات» تظهر شاشتان مستقلتان: «كشف حساب طالب» و«مراجعة وسجل المدفوعات». لا يُعرض أي كشف مالي قبل اختيار طالب من القائمة.
* يمكن البحث عن الطالب ثم اختياره؛ يظهر تقريره وحده ويحتفظ بنفس معادلات رصيد المقدم، المدفوع، المؤخر، تفاصيل الحصص، وحركة التحويلات.
* شاشة المراجعة تبدأ بالمدفوعات «بانتظار المراجعة»؛ يمكن اختيار المعتمدة أو المرفوضة أو الأرشيف أو كل التحويلات.
* نموذج وسجل المدفوعات اليدوية لم يُحذف، لكنه صار داخل قسم قابل للفتح «تسجيل أو تعديل دفعة يدوية».
* التحويلات المعلقة لا تُضاف للمدفوع المعتمد قبل الموافقة؛ لا يتم اعتماد التحويل دون تأكيد إداري حسب الآلية القديمة.

## الحضور والغياب
* أربع شاشات منفصلة: «تسجيل حصة»، «سجلات الحصص»، «ملخصات وتقارير»، «أدوات المعلمين».
* سجلات الحصص تحتوي نفس فلاتر المعلم/المادة/الطالب والتاريخ وحالة الحضور والمدفوعات، مع أزرار الإضافي وأدوات الطباعة في شاشة السجل.
* أدوات ربط المعلمين القديمة وإصلاح UID محفوظة لكن لم تعد مزدحمة وسط السجل.
* تعديل الواجهة فقط، ولا تُعدَّل سجلات Firebase أو قواعد المدفوعات.

## الاختبار والنشر
* اختبرنا التنقل بين الأقسام في متصفح Chromium محلي باستخدام DOM مُعزَّل، واختبرنا اختيار طالبين ببيانات مالية تجريبية؛ لم يظهر حساب قبل اختيار طالب، ولا يظهر إلا حساب واحد بعد اختياره.
* اختبارات الملفات وJavaScript سليمة. لم يكتمل اختبار الحسابات الحقيقية أو اعتماد تحويل فعلي في Firebase؛ يُرجى اختبار حساب الأدمن والحضور والتحويلات قبل اعتماد الموقع الحي.
* ارفع نسخة احتياطية من المجلد الحالي قبل استبدال الملفات، وحدث الصفحة بـ Ctrl+F5.
* لم نغير firestore.rules في هذا التحديث.
