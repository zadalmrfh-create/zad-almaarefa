تعديل حذف الأستاذ علي عبد الحميد — ملف التعديل فقط

الملف المطلوب رفعه إلى GitHub Pages:
  teachers/index.html

طريقة التركيب:
1) فك الضغط.
2) افتح مستودع موقع زاد المعرفة على GitHub.
3) استبدل الملف teachers/index.html بالملف المرفق مع الحفاظ على نفس المسار.
4) احفظ التعديل (Commit) وانتظر اكتمال نشر GitHub Pages ثم افتح صفحة طاقم التدريس مع Ctrl + Shift + R.

هذا التعديل يخفي بطاقة الأستاذ علي من صفحة طاقم التدريس حتى لو ظلت بياناته القديمة داخل Firestore، ولا يحذف السجلات المالية أو الحضور القديمة.
إذا كانت البطاقة تظهر بعد نشر الملف الجديد، تحقق من أنك تفتح نفس موقع GitHub Pages وأن التعديل نُشر بالفعل.
