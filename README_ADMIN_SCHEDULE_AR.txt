زاد المعرفة — متابعة الأدمن وجداول الطلاب

النشر
١. في Firebase Console ادخل على Firestore Database ثم Rules.
٢. أضف الكتلة الموجودة في FIRESTORE_PRIVATE_SCHEDULE_SNIPPET.txt داخل
   match /databases/{database}/documents في القواعد الحالية ثم اضغط Publish.
   تستخدم الكتلة دالة isAdmin الموجودة في قواعد المنصة. صلاحية قراءة الحصة
   الخاصة للأدمن وصاحب الحساب المستهدف، وصلاحية إدارة الحصة للأدمن.
٣. فك الضغط وانقل مجلدَي dashboard وstore إلى جذر مشروع GitHub مع استبدال الملفات المطابقة.

لوحة الأدمن
- «المطلوب النهارده» يجمع الحجوزات، والتحويلات، والمقالي، وطلبات المتجر المعلقة.
- اضغط عدّاد المتجر لفتح الطلبات المعلقة مباشرة في إدارة المتجر.
- «مواعيد الحصص والتقارير» داخل نفس الكارت وفيه عرض وطباعة وتصدير حصص
  التاريخ المختار من سجل المحاضرات العام، واختصارات التقارير الموجودة.
- من تبويب «جداول الطلاب» اختر حساب الطالب وأضف عنوان الحصة والمادة والموعد
  بتوقيت القاهرة. يمكنك إضافة اسم المعلم ورابط الحصة، وتعديل الموعد وإلغاء الحصة بعد الحفظ.

لوحة الطالب
- بعد فتح اللوحة أو تحديثها تظهر حصصه الخاصة ضمن جدوله الأسبوعي،
  وفي المحاضرات وبطاقة الحصة القادمة حسب الموعد.
- رابط الحصة يظهر في صفحتها ويفتح وفق وقت الدخول المعتاد.
