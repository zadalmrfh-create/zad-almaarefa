زاد المعرفة — إصلاح الحجز في اللغات الأربع (2026-10-20)

المشكلة: ترجمات Google Translate قد تغيّر نصوص الاختيارات؛ حقول طريقة الحصة والأيام والفترة كانت تفتقد قيمة value ثابتة.

التعديلات:
1) sections/booking/index.html: قيم HTML صريحة لقوائم الأيام، الفترات وطريقة الحصة.
2) sections/booking/booking.js: كل الاختيارات تُحوّل قبل الإرسال إلى قيم عربية أصلية ثابتة بناءً على الخيار المحدد، دون الاعتماد على النص المترجم؛ وبهذا لا تختلف بيانات Firestore بين العربية والإنجليزية والروسية والفرنسية.
3) firestore.rules: الحفاظ على قواعد الحجز الآمنة، والتحقق من نظام التعليم بالقيم العربية الثابتة.

التثبيت:
- ارفع ملفات المشروع إلى GitHub Pages بما فيها sections/booking/booking.js و sections/booking/index.html.
- افتح Firebase Console > Firestore Database > Rules وانسخ محتوى firestore.rules ثم انشر القواعد المناسبة لمشروعك بعد مراجعتها.
- احرص على نسخ القواعد الحالية احتياطيًا قبل الاستبدال.
- جرّب طلب الحجز من حساب طالب حقيقي في اللغات الأربع، وأعد تحميل الصفحة بعد الرفع لمسح الكاش.

اختبارات محلية: تم تشغيل أربع حالات محاكاة لعناصر النموذج وعمليات Firebase، وانتهت كلها بنجاح. لم يتم اختبار اتصال Firebase الفعلي.
