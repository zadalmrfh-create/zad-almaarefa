زاد المعرفة — تحديث حذف تقييمات المعلمين والمنصة والإدارة

هذا التحديث مبني على آخر حزمة جداول الطلاب الأسبوعية. لا يحتوي المشروع الكامل ولا مجلد public.

التركيب:
1. احتفظ بنسخة احتياطية من المشروع وقواعد Firestore الحالية.
2. فك الضغط داخل المجلد الرئيسي بجوار index.html وpackage.json مع استبدال الملفات المتطابقة.
3. شغّل npm run release:check من CMD داخل المجلد الرئيسي باستخدام Node.js 24 كما في التحديثات السابقة.
4. قبل نشر الموقع، افتح Firebase Console > Firestore Database > Rules.
   في قواعدك الحية، ابحث عن match /weeklyReviewPrivate/{reviewId} ثم match /weeklyTeacherFeedback/{feedbackId}.
   داخل كل منهما فقط استبدل السطر:
     allow update, delete: if false;
   بالسطرين:
     allow update: if false;
     allow delete: if isCertificateAdmin();
   الدالة isCertificateAdmin موجودة أصلًا في قواعد المشروع المرفقة. إن لم تكن موجودة في القواعد الحية، قارنها بقواعد المشروع وانقل تعريفها المطابق قبل النشر. لا تستبدل سائر القواعد الحية دون مراجعة، خصوصًا إن أجريت تعديلات أحدث عليها.
   اضغط Publish. ملف firestore.rules المرفق يحوي هذين التعديلين فقط فوق آخر نسخة معروفة من قواعد المشروع.
5. ارفع الملفات المعدلة على GitHub ثم افتح الموقع بعد انتهاء النشر واضغط Ctrl+F5.
6. من لوحة الإدارة > التقييمات (مركز جودة التعليم)، اضغط حذف التقييم بجوار التقييم المطلوب ثم أكد الحذف.

السلوك:
- يسمح الحذف فقط للإدارة المصرح لها. التعديل اليدوي للدرجات ما زال ممنوعًا.
- الحذف نهائي؛ إذا كانت فترة التقييم لا تزال مطلوبة، قد يُطلب من الطالب إرساله مجددًا.
- يحذف السجل الخاص ونسخة المعلم المرتبطة به والنسخ العامة المحددة بدقة في عملية واحدة، ويعيد حساب المتوسطات والفلاتر.
- إذا كانت هناك نسخ عامة قديمة ذات معرّفات عشوائية، فلا يحذفها اعتمادًا على تشابه النص وحده. قد يلزم مراجعتها يدويًا؛ عند وجود أكثر من تطابق مؤكد يتوقف الحذف لحين المراجعة.
- لم تُعدّل بيانات الطلاب أو التقييمات الحقيقية، ولم تُنشر قواعد Firestore الحية. الاختبارات محلية بمحاكاة قاعدة البيانات وليست اختبار صلاحيات على Firebase الحية.
