# تحديث شامل لمنصة زاد المعرفة

تم تطوير المشروع مع استثناء ميزتين حسب الطلب:
- لم يتم إضافة نظام دروس جديد.
- لم يتم إضافة/توسيع Push Notifications.

## ما تم تطويره
- ملف الطالب: تعديل الاسم والهاتف والبلد والمدينة والصف.
- إحصائيات الطالب: الاختبارات، متوسط الدرجات، الحجوزات، عناصر المكتبة.
- لوحة المعلم: إحصائيات الطلاب والحجوزات والاختبارات والحضور، مع عرض البلد والمدينة.
- لوحة الأدمن: إحصائيات مباشرة للمستخدمين والطلاب والمعلمين والاشتراكات والحجوزات والاختبارات والتسجيلات اليومية.
- بحث وتصفية المستخدمين حسب الاسم/البريد/الهاتف/المدينة، النوع، الحالة، والبلد.
- تصدير حسابات المستخدمين CSV.
- تحسينات SEO وOpen Graph وStructured Data والـ preload للصفحة الرئيسية.
- تحسينات قواعد Firestore لملفات المستخدمين وإضافة قواعد سجل العمليات والشهادات.
- تصميم متجاوب للتحسينات الجديدة على الهاتف.

## لم يتم حذف أنظمة المشروع الموجودة مسبقًا
الاختبارات، المحاضرات المباشرة، الحجوزات، الاشتراكات، المكتبة، الإشعارات الداخلية، إدارة المحتوى وغيرها بقيت كما هي.


## إضافات هذه النسخة
- مركز اختبارات كامل: اختيار من متعدد، صح/خطأ، ترتيب، وقت، محاولات، درجة نجاح، اختبار نهاية الوحدة، وبنك أسئلة.
- متابعة المحاولات ونتائج الاختبارات في لوحة الأدمن وحساب الطالب.
- تطوير المحاضرات المباشرة: عداد للموعد، اختبار قبل المحاضرة، اختبار اختياري بعد المحاضرة باستخدام نفس الأسئلة، تسجيل فتح Meet، وتقييم المحاضرة.
- الإشعارات داخل الموقع: الجميع، الطلاب، المعلمين، صف محدد، قسم محدد، أو مستخدم محدد، مع سجل ومقروء/غير مقروء.
- لا تستخدم هذه النسخة Firebase Storage أو Push Notifications.
