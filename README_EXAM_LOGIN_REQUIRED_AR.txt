زاد المعرفة | حماية الامتحانات بتسجيل الدخول

ما تم تغييره:
1- صفحات الاختبارات في sections/tests تتأكد من Firebase Authentication قبل إظهار محتوى الامتحان.
2- فتح رابط امتحان مباشر بدون جلسة يذهب لتسجيل الدخول، ثم يعود إلى نفس الرابط بعد نجاحه.
3- حماية قراءة الامتحانات الإلكترونية الديناميكية (codeExams وشظايا chunks) من غير المسجلين عن طريق قواعد Firestore.
4- إنشاء حساب جديد من صفحة التسجيل يعيد الطالب للامتحان المطلوب بعد التسجيل.

النشر:
- ارفع ملفات ZIP الجديدة إلى GitHub Pages.
- حدث Firestore Security Rules من الملف firestore.rules وانشرها (Publish).
- اختبر في نافذة خاصة: فتح امتحان، تسجيل الدخول، العودة إلى نفس الامتحان؛ ثم اختبر دخول مستخدم مسجل أصلًا.

ملاحظة مهمة:
- صفحات النحو والبلاغة والتوحيد HTML ثابتة، ولذلك منع عرضها من الواجهة لا يخفي مصدر HTML أو يمنع الاطلاع عليه بطرق تقنية. حماية كاملة لمحتوى هذه الصفحات تتطلب وضع محتوى الأسئلة في مصدر محمي من الخادم بدلاً من نشره داخل ملف HTML عام.
- نتائج الاختبارات الإلكترونية المرسلة من المتصفح ليست نتائج مصدّقة إداريًا.
