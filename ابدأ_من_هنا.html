تحديث طاقم زاد المعرفة

هذا التحديث يضيف الأستاذ محمد طلعت عبدالله إلى طاقم التدريس والحجز والحضور والغياب، ويمنع ظهور بلال فرغلي في القوائم النشطة. مرتبات محمد طلعت الموجودة لن تتغير، ولا يحذف أي سجلات مالية محفوظة.

طريقة العمل

  1. من GitHub افتح مستودع المنصة واختر Code ← Download ZIP لتحميل أحدث نسخة.
  2. اختر ملف ZIP الجديد في الخانة أدناه.
  3. اضغط «إنشاء ملفات التعديل فقط» لتحصل على ZIP يحتوي الملفات المعدلة وصورة الأستاذ فقط، دون تغيير باقي المشروع.
  4. فك ضغط الملف الناتج، وارفع الملفات إلى نفس المسارات داخل GitHub ثم انشر الموقع.
كل شيء يتم محليًا على جهازك؛ لا يتم إرسال ملفات المنصة لأي سيرفر.

لم يتم اختيار الملف بعد.



بعد النشر: ادخل بحساب الأدمن إلى «إدارة المحتوى ← طاقم التدريس» واضغط «إضافة بطاقة الأستاذ محمد طلعت للإدارة» إذا كان الزر ظاهرًا. هذا يحفظ بطاقته في Firestore دون إضافة أو تعديل أي مرتبات. جرّب بعد ذلك اختيار اللغة الإنجليزية في الحضور والغياب والحجز.
