# صفحة سياسة المدفوعات — أكاديمية زاد المعرفة التعليمية

تمت إضافة صفحة عامة مستقلة `sections/payment-policy.html` بتصميم متجاوب على الهاتف والكمبيوتر، ونص السياسة الذي اعتمدته الإدارة كما هو في الرسالة الأخيرة (مع ضبط همزات الكتابة فقط).

طرق الوصول:
- الصفحة الرئيسية: قسم مخصص لسياسة المدفوعات، وقائمة «المزيد» على الكمبيوتر والهاتف، والفوتر.
- لوحات الطالب والمعلم والأدمن: رابط «💳 سياسة المدفوعات» في الشريط العلوي.
- رابط مباشر من جذر الموقع: `sections/payment-policy.html`.

لا تحتاج الصفحة لتسجيل الدخول، لأنها تنص على سياسة عامة، ولا تقرأ أو تعدل أي بيانات في Firebase.
زر «طباعة السياسة» يستخدم `window.print()` ويطبع محتوى السياسة دون القوائم.

لم تتغير أي قواعد Firebase أو حسابات المدفوعات أو إجراءات التحصيل/الصرف. هذه إضافة معلوماتية فقط.
