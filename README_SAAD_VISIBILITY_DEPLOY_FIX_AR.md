# إصلاح عدم ظهور الأستاذ سعد علاء — نسخة جاهزة للنشر

## التشخيص المؤكد
- ملف الأستاذ سعد موجود بالفعل في GitHub، لكن زر إضافة ملفه في لوحة الإدارة لم يكن ظاهرًا في تبويب واضح: أداة تقسيم لوحة الإدارة نقلت البطاقات غير المصنّفة تلقائيًا إلى تبويب «الإشعارات»؛ أضفنا تبويب «إعداد المعلمين» وربطنا بطاقة سعد به.
- صفحة الحجز تختار المعلم بعد كتابة المادة. أضفنا بطاقة حجز مرئية وواضحة باسم الأستاذ سعد، تربط الرياضيات باسمه. المواد الأخرى تستمر في عرض اختيار المعلم.
- إعلانات المدرس والصورة كانت في كود صفحة طاقم التدريس، لكن لا يمكن الجزم بتحديث النسخة المنشورة من GitHub بمجرد رفع الملفات. أضفنا بطاقة HTML احتياطية مرئية حتى لو فشل تحميل Firebase، مع إصدار جديد للصور والملفات لتخفيف مشكلة التخزين المؤقت.

## النشر على GitHub (ضروري)
1. النسخة المضغوطة الجديدة تحتوي **ملفات المنصة مباشرة عند فتح ZIP** وليس مجلدًا إضافيًا حولها.
2. انسخ *المحتويات نفسها* إلى جذر المستودع `zadalmrfh-create/zad-almaarefa` في الفرع الذي ينشر منه الموقع، واستبدل الملفات القديمة واحتفظ بباقي الملفات.
3. اذهب إلى Settings > Pages وتأكد من نشر الفرع main والمجلد /(root)، أو من الإعداد الصحيح الذي تستخدمه فعلًا. إذا كان عنوان الموقع Vercel، تأكد أن Vercel متصل بالمستودع والفرع الصحيحين وأن آخر Deployment تم بنجاح. GitHub Pages وVercel موقعان/عمليتا نشر مختلفتان.
4. افتح الصفحة الفعلية `teachers/index.html` وابحث عن «تحديث المعلمين — 10 نوفمبر 2026 • إصدار 2». عدم ظهور العبارة يعني أن الموقع يعرض ملفات قديمة أو إصدارًا مختلفًا. جرّب Ctrl+Shift+R، وراجع رابط الموقع ومنصة الاستضافة أولًا.
5. افتح `sections/booking/index.html`، ستظهر بطاقة أ/ سعد مباشرة فوق الفورم.
6. سجّل دخول الإدارة إلى `dashboard/admin/index.html` ثم افتح تبويب «إعداد المعلمين» واضغط «إضافة ملف سعد علاء للإدارة» مرة واحدة. هذا يحفظ بطاقة المعلم في مجموعة `teachers` بـFirestore، ويحتاج اتصال Firebase وصلاحية إدارة وحصة استخدام متاحة.
7. لإنشاء حساب معلم حقيقي: يجب تسجيل سعد حسابًا حقيقيًا في Firebase Authentication/`users`، واعتماده معلمًا نشطًا. هذا الإجراء لا يتم تلقائيًا بتحميل ملفات الموقع، ولا يمكن إنشاء UID أو كلمة مرور وهمية.
8. بعد ربط الحجوزات والحضور بمعرّف UID الصحيح، تصبح سجلات الطلاب والمرتب ونتائج الامتحانات الخاصة به متاحة حسب قواعد Firestore ومزامنة صلاحيات نتائج المعلمين.

### روابط الصفحات الصحيحة داخل الموقع
- طاقم التدريس: `teachers/index.html`
- الحجز: `sections/booking/index.html` (ليس `booking.html` في جذر المشروع)
- الإدارة: `dashboard/admin/index.html`

لم يتم الاتصال بقاعدة Firebase الفعلية، ولم يتم تعديل أي حساب أو سجلات مالية حقيقية. اختبر بحسابات إدارة/معلم/طالب بعد نشر الملفات والتأكد من القواعد.
