زاد المعرفة | تقييم آخر محاضرة فقط + رابط مباشر للمشاركة
12 نوفمبر 2026

التعديلات:
- عند تسجيل «حاضر» في لوحة الإدارة، يتم تعيين آخر محاضرة قابلة للتقييم للطالب، داخل سجل latestLectureReview/{studentUid}.
- زر «نسخ لينك التقييم» يظهر في صف آخر محاضرة قابلة للتقييم، داخل سجل الحضور؛ ينسخ رسالة جاهزة للإرسال على واتساب يدويًا.
- الطالب الذي يفتح الرابط يسجل الدخول بحسابه؛ يفتح تبويب تقييم المحاضرات مباشرة.
- المحاضرات الأقدم تظهر للعرض فقط، ولا يوجد بها زر تقييم؛ ومحاولة إرسال تقييم قديم تُرفض بواسطة قواعد Firestore.
- التقييمات القديمة التي أرسلها الطلاب محفوظة للإدارة ولا تُحذف.
- رابط التقييم ليس رابطًا عامًا: يشترط تسجيل الدخول بنفس حساب الطالب.
- لا توجد رسوم مراسلة واتساب: الرسالة ينسخها الأدمن ويرسلها يدويًا.

النشر:
1- خذ نسخة احتياطية من المستودع ثم فك ZIP وارفع محتوياته إلى جذر فرع main مع الاحتفاظ بالمسارات.
2- مهم: ادمج قواعد latestLectureReview وlectureReviews الموجودة بملف firestore.rules مع قواعد Firestore المنشورة في Firebase Console ثم انشرها. رفع ملف قواعد إلى GitHub وحده لا ينشر قواعد Firebase.
3- بعد نجاح نشر GitHub Pages، سجّل حصة تجريبية جديدة «حاضر».
4- من جدول الحضور انسخ الرابط بجوار الحصة وأرسله للطالب، ثم افتحه بحساب الطالب.
5- سجّل حصة ثانية للطالب: رابط الحصة الأولى يجب أن يغلق، وتظل الثانية فقط متاحة.

توافق البيانات القديمة:
- لن يظهر زر نسخ التقييم على سجلات ما قبل تحديث القواعد حتى يُنشأ مؤشر latestLectureReview عند تسجيل حصة جديدة (أو تعديل حصة من غائب إلى حاضر).
- التقييمات القديمة تظل موجودة ولا تتأثر بالحزمة.
- لا يوجد حذف تلقائي لسجل الحضور أو المدفوعات.

ملاحظات:
- النظام لا يرسل واتساب تلقائيًا؛ نسخ الرابط وإرساله مجانًا يدويًا.
- لم يتم اختبار النسخة ضد مشروع Firebase الحقيقي، ويجب تجربة حساب طالب اختباري بعد النشر.
