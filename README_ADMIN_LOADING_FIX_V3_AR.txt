إصلاح لوحة إدارة زاد المعرفة — نسخة v3

المشكلة المؤكدة:
ملف dashboard/admin/index.html في النسخة السابقة كان ينتهي داخل دالة ensureLegacyTeachers، بدون إغلاق دالة JavaScript ولا وسم </script> ولا بقية الصفحة.
نتيجة ذلك SyntaxError: Unexpected end of input، وبالتالي لا ينفذ تحميل المستخدمين من Firebase وتظل عبارة "جارٍ التحميل".

الإصلاح:
- استكمال الدالة وإغلاق سكربت الصفحة والـ HTML بصورة صحيحة.
- إعادة ربط ملفات الإحصائيات والفلاتر والتقارير والحجوزات والحضور والإشعارات التي كانت غير محملة.
- استكمال الوظائف الناقصة لقائمة الحجوزات وعداد الطلاب وإدارة المحتوى.
- عرض أخطاء تحميل المستخدمين في الصفحة بدلًا من تعليق صامت، مع زر لإعادة المحاولة.

طريقة الرفع إلى GitHub Pages:
1- يمكن رفع ملف dashboard/admin/index.html الجديد بدل القديم مع بقاء المسارات.
2- أو فك ZIP ورفع جميع الملفات والمجلدات بنفس ترتيبها الموجود هنا.
3- انتظر نشر GitHub Pages ثم حدّث الصفحة Ctrl+Shift+R.
4- إذا ظهرت رسالة permission-denied بعد ذلك، تأكد أن قواعد firestore.rules المرفقة منشورة في Firebase Console. رفع ملف القواعد إلى GitHub لا ينشرها تلقائيًا.

التحقق:
اجتازت نسخة JavaScript الرئيسية فحص الصياغة node --check.
لم يتم اختبار اتصال حي بحساب Firebase الخاص بك؛ لذا لا يمكن الجزم بسلامة قواعد Firebase المنشورة لديك.
